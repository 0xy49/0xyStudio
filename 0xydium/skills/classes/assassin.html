🟦🟩🟥 VERSION SIMPLIFIÉE DU SKILLTREE

ROOT : Attack Speed (AS)

Le cœur du gameplay Assassin repose sur :
➡️ la vitesse d'attaque, permettant d’enchaîner rapidement les coups.

C’est la statistique qui donne l’identité globale de la classe.

🟦 BRANCHE CYAN — Movement Speed (MS)

Thème général : mobilité, vitesse, repositionnement

🔹 Cette branche améliore :

  • MS → déplacement plus rapide
  • SS → vitesse de nage, fluidité
  • LUCK → bonus aléatoires utiles
  • AD → agilité offensive
  • DS / AS → vitesse générale d'exécution

Style de gameplay :
➡️ L’assassin rapide, insaisissable, capable d’entrer/sortir du combat à volonté.

🟩 BRANCHE VERTE — Draw Speed (DS)

Thème général : vitesse de tir, attaque à distance, cadence

🔹 Boosts importants :

  • DS → plus grande cadence d’arc
  • AD → dégâts directs supplémentaires
  • SS → mouvement contrôlé
  • MS → mobilité de repositionnement
  • EG → progression accélérée

Style de gameplay :
➡️ Assassin Archer, tir rapide, burst à distance, attaques instantanées.

🟥 BRANCHE ROUGE — Crit Chance (CC)

Thème général : dégâts critiques, burst, exécutions rapides

🔹 Principales améliorations :

  • CC → probabilité de coups critiques
  • ARD → dégâts de flèches renforcés
  • AS → vitesse de frappe
  • LUCK → bonus favorisant les coups critiques
  • MH / MS → petites touches défensives/mobilité

Style de gameplay :
➡️ Assassin orienté burst, frappant très fort sur un court instant, basé sur le crit.
